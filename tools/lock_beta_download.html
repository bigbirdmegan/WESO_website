Lock the beta download

Encrypts the download link with a password for the ARU Review beta page. Everything happens in this browser window; nothing is sent anywhere, and the password isn't saved.

Next:

  1. Save the file into the website's data folder as beta_locked.json (replace the old one if there is one).
  2. In RStudio: Build > Build Website (or rmarkdown::render_site()).
  3. Commit and push as usual. The page is at kennicottii.ca/aru_review_beta.html.
  4. Send testers the page link and, separately, the password (e.g. one by email and one by text).
